# Project 05 — Traffic Light FSM

A six-state Moore finite-state machine for a two-road traffic-light controller, written in Verilog and simulated in Vivado.

## Inputs
- `clk`: clock input, generated by the testbench with a 10 ns period.
- `reset`: synchronous, active-high reset. At a rising clock edge while reset is high, the FSM returns to `S0` and the counter is cleared.
- `SB`: sensor for a vehicle on road B.

## Outputs
- Road A: `Ay` (green), `As` (yellow), `Ak` (red)
- Road B: `By` (green), `Bs` (yellow), `Bk` (red)

## State sequence
| State | Road A | Road B | Transition |
|---|---|---|---|
| `S0` | Green | Red | Remain while waiting; when `counter == 10` and `SB == 1`, go to `S1` |
| `S1` | Yellow | Red | `S2` |
| `S2` | Red | Yellow | `S3` |
| `S3` | Red | Green | Go to `S4` when `counter == 10` |
| `S4` | Red | Yellow | `S5` |
| `S5` | Yellow | Red | `S0` |
